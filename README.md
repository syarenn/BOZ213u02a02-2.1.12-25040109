# Python print() Fonksiyonu – sep ve end Parametreleri

## ⚙️ sep ve end Parametreleri

**sep Parametresi:**

`print()` fonksiyonunda birden fazla ifade arasına hangi karakterin yerleştirileceğini belirler.

Örnek:

`print("Python", "Programlama", sep="-")`

Çıktı:

`Python-Programlama`

**end Parametresi:**

`print()` fonksiyonunun sonunda hangi karakterin kullanılacağını belirler. Varsayılan olarak yeni satıra geçilir.

Örnek:

`print("Merhaba", end=" ")`

`print("Python")`

Çıktı:

`Merhaba Python`
